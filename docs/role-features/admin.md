# نقش مدیر (admin / manager)

> منبع: `frontend/src/app/app.routes.ts` + `features/admin/*` + آرشیو «تربیت مربی» (`D:\اسناد\Tarbyatemorabbi_cleaned`)

## خلاصه
نقش مدیر بالاترین سطح دسترسی عملیاتی سیستم است: مدیریت کامل متربیان، مربیان، دوره‌ها، شعب، مکاتب، برنامه درسی، حلقه‌ها، والدین، ارزیابان، نظرسنجی‌ها و گزارش‌های ستادی.

## مسیریابی و دسترسی
- نقطه ورود: `/admin` (هدر: «داشبورد مدیریت»)
- گاردها: `authGuard` + `adminGuard` (نقش‌های مجاز: `admin`, `manager`, `headquarters`, `branch_manager`)
- ورود خودکار از صفحه لاگین برای نقش‌های `admin`/`manager` به `/admin`

## قابلیت‌ها
- **متربیان**: افزودن متربی جدید، جستجو (نام/نام کاربری/کد/ایمیل)، انتخاب چندتایی و حذف گروهی
- **مربیان**: افزودن مربی جدید، جستجو (نام/نام کاربری/تخصص)، انتخاب چندتایی و حذف
- **مسئولین شعب**: افزودن مسئول جدید، جستجو (نام/نام کاربری/شعبه/استان)، انتخاب چندتایی
- **شعب**: افزودن/ویرایش/حذف شعبه، جستجو
- **دوره‌ها**: ایجاد دوره جدید، فیلتر (عنوان/کد/مدرس + وضعیت فعال/غیرفعال/آرشیو)، مدیریت تکالیف و پیوست‌ها، ثبت‌نام‌ها و کد دعوت
- **مکاتب**: دو تب «مدیریت مکاتب» و «مدیریت شعب مکتب»، دسته‌بندی دخترانه/پسرانه در سایدبار
- **برنامه درسی**: تب‌های حوزه‌های درسی / روش‌های تدریس / کتاب‌ها / اهداف درسی + ایجاد هرکدام
- **حلقه‌ها**: جستجو، افزودن حلقه جدید، مدیریت متربیان/کتاب‌ها/روش‌های تدریس هر حلقه
- **ستاد مرکزی**: سه تب خلاصه آمار، عملکرد شعب، عملکرد مربیان
- **نظرسنجی‌ها**: داشبورد خلاصه (کل نظرسنجی‌ها/فعال/کل پاسخ‌ها/میانگین نمره/اقدامات باز)، نظرسنجی جدید، تب‌های سؤالات / اقدامات / تحلیل
- **مسیر معنوی**: ثبت تمرین روزانه پنج‌گانه، مناسبت‌ها، تاریخچه، Streak

## دسترسی به محتوای «تربیت مربی»
- **خیر، مستقیم**: مسیر `/training-courses` فقط با `roleGuard('trainee')` محافظت شده و برای مدیر لینکی در ناوبری ندارد.
- **به‌صورت غیرمستقیم**: مدیر تمام داده‌های آموزشی که از محتوای این آرشیو می‌آیند را مدیریت می‌کند (دوره‌ها، برنامه درسی، حلقه‌ها، مکاتب) و خروجی نظرسنجی‌ها و ارزیابی‌ها را می‌بیند.

- رسیدگی به مسائل ساختاری: «فرم برگه سوال مربی یاران»، «فرم تجزیه و ترکیب مربی‌یاران»، «توضیح طرح درس و گزارش»

## محتوای عملیاتی استخراج‌شده از آرشیو (بدنه‌ی متن)

### جایگاه مدیر در ساختار اجرایی (سند جامع ۱.۰/۲.۰)
- مدیر/مدیریت = اجراساز چارچوب کلی ستاد در سطح سازمان
- **فرایند جذب مربی**: مباحث ← آزمون ← خلاصهٔ جلسات ← مصاحبه (کاغذی + عملی در مکتب) ← سنجش توانمندی
- **فرایند جذب متربی**: تبلیغات ← ارتباط ← مصاحبه ← بسنجی شرایط ← فرم به والدین/دریافت

### ساختار استاندارد شعبه (مدل ایده‌آل)
- ۶۶ متربی / ۶ حلقه / ۱۱ نفر در هر حلقه + ۶ مربی + ۱ ارزیاب + ۱ هماهنگ‌کننده
- مسئول شعبه: حداقل ظرفیت ۸ ساعت، ترجیحاً غیرمربی
- هماهنگ‌کننده: کار غیرتدریسی نمی‌کند

### فرایند ۷ مرحله‌ای تربیت مربی (سند جامع، بند ۴)
- شناخت/انتخاب ← توجیه/هم‌افق‌سازی ← آموزش پایه ← تمرین/مشاهده ← مسئولیت تدریجی ← مربی‌گری مستمر ← ارزیابی/تثبیت
- **نسل بعدی مربی از بین متربیان**: شناسایی استعداد ← مسئولیت متناسب ← مشارکت ← مربی‌یار

### سیستم مالی (سکه‌ای)
- حق‌ال‌تفریح ماهانه به گرم طلا، حقوق مربی به طلّای، قیمت‌گذاری ۵ ساله
- صندوق قرض‌الحسنه برای پس‌انداز/برداشت
- هزینه‌های جاری: دفترچه، فرم ارزیابی، ماژیک، لیست حضور/غیاب، فرم گزارش
