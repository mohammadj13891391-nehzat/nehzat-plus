## ۱. OTUH2 — احراز هویت متمرکز (احراز هویت)

**نقش:** ارائه‌دهنده هویت برای کل اکوسیستم. توکن‌های OAuth2/OIDC صادر می‌کند و مدیریت کاربران با فرآیند تأیید مدیریت را انجام می‌دهد.

### امکانات
- **صدور توکن‌های OIDC**: پشتیبانی کامل از OAuth2/OIDC با OpenIddict
- **مدیریت کاربران**: ثبت‌نام خودکار + فرآیند تأیید توسط مدیر
- **مدیریت نقش‌ها**: تعریف و تخصیص نقش‌ها به کاربران
- **مدیریت Client‌ها**: تنظیمات OIDC برای هر سرویس
- **API داخلی**: برای provision کاربران توسط سایر سرویس‌ها (با کلید API)
- **UI ورود**: صفحه ورود متمرکز با جریان redirect
- **Sync کاربران**: OidcSyncMiddleware در سرویس‌های دیگر

### Endpoints
```
/api/admin/*          - مدیریت کاربران، نقش‌ها، Client‌ها (نقش admin)
/api/auth/register    - ثبت‌نام
/api/internal/*       - API داخلی سرویس‌ها (X-API-Key)
/auth/login           - صفحه ورود
/connect/*            - Endpoints OIDC (authorize, token, logout, userinfo)
/.well-known/openid-configuration - OIDC Discovery
```

## ۷. Nehzat Tarbiyati — سامانه مستقل نهضت تربیتی

- **Entity‌ها**: Maktab, Branch, AppUser, Report, Lesson, Person, Attendance, Session, Notice, Criterion, Evaluation, Comment, Point, Recognition, QuranItem, Hadith, Methodology, TaskItem, DailyTrack, ChatMessage, AppSetting

#### Frontend
- **اپ تک‌صفحه‌ای**: فارسی (RTL)
- **localStorage**: ذخیره محلی + push با debounce
- **Sync**: Pull در init + Push با sv()

### Endpoints

## ۸. Gateway — درگاه معکوس (Reverse Proxy)

**نقش:** مسیریابی یکپارچه ترافیک به سرویس‌های مختلف با YARP.

### مسیریابی
```
/oauth/*        → OTUH2 (:5000)
/lesson/*       → Nehzat (:3000)
/share/*        → Mokhmmas (:5119)
/personality/*  → Shakhsiat-Yab (:3002)
/shop/*         → Hamyar (:5067)
```

### امکانات
- **Path Rewrite**: حذف prefix از مسیر
- **Reverse Proxy**: فوروارد به کلسترهای مناسب
- **Load Balancing**: پشتیبانی از چند destination

### پیکربندی
- **Clusters**: authCluster, lessonCluster, shareCluster, personalityCluster, shopCluster
- **Routes**: auth, lesson, share, personality, shop
- **Transforms**: PathRemovePrefix

## نکات فنی

### معماری
- **Clean Architecture**: API → Application → Domain ← Infrastructure
- **EF Core**: ORM با SQL Server (بعضی SQLite در dev)
- **OIDC**: OpenIddict در OTUH2
- **Minimal API**: Mokhmmas و Tarbiyati
- **Angular 21/22**: Standalone components, lazy loading

### امنیت
- **JWT**: at+jwt (OpenIddict)
- **JWKS**: Validation distributed
- **X-API-Key**: API‌های داخلی
- **CSRF**: Hamyar
- **Audit Log**: Mokhmmas

### همگام‌سازی
- **OidcSyncMiddleware**: در همه سرویس‌ها
- **Snapshot Sync**: Tarbiyati (baseRevision + 409)
- **Push Notification**: Morabbi
