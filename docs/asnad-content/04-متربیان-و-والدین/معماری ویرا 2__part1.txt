## ۱. مقدمه و چشمانداز

پلتفرم **«نهضت تربیتی حضرت سیدالشهدا علیه السلام»** یک سامانه جامع مدیریت آموزشی و تربیتی است که بر اساس الگوی اسلامی و با محوریت اهلبیت (ع) طراحی شده. این پلتفرم فرآیند تربیت و آموزش را از بدو تولد تا ۲۱ سالگی پوشش میدهد.

### ۱.۱. اهداف کلان

- ایجاد نظام تربیتی یکپارچه مبتنی بر **ثقلین** (قرآن و عترت)
- تربیت نسلی متعهد، متخصص و آشنا با سبک زندگی اسلامی
- پوشش کامل سنی ۰ تا ۲۱ سال با تفکیک جنسیتی متناسب
- توانمندسازی والدین به عنوان اولین مربیان
- ایجاد مسیر رشد شفاف برای همه نقشها
- **ایجاد کانال ارتباطی مؤثر و دوطرفه بین والدین، مربی و مکتب** (بازخورد کاربران)
- **ارائه گزارش فردی و دقیق از عملکرد هر متربی** (بازخورد کاربران)
- **انتشار سریع MVP برای دریافت بازخورد واقعی** (بازخورد کاربران)

### ۱.۲. اصول معماری

- **نقشمحوری**: همه چیز حول نقش کاربران تعریف میشود
- **سلسلهمراتب شفاف**: هر نقش دسترسیها و مسئولیتهای مشخص دارد
- **ارزیابی مستمر**: سیستم ارزیابی تصادفی برای تضمین کیفیت
- **انعطافپذیری**: هر کاربر میتواند در چند مکتب عضو باشد
- **قابلیت توسعه**: امکان افزودن شعبه در استانها و کشورهای مختلف
- **حفظ با تدبر**: صرف حفظ الفاظ، حفظ محسوب نمیگردد
- **شفافیت برای والدین**: والدین باید از عملکرد دقیق فرزند خود مطلع باشند
- **انتشار سریع MVP**: دریافت بازخورد واقعی زودتر از تکمیل کامل

## ۴. داستانهای کاربری

### ۴.۱. متربی (۱۷ داستان)

#### ثبتنام و ورود
1. **ثبتنام**: فرم شامل نام، نامخانوادگی، نام کاربری، ایمیل، شماره تماس (`09xxxxxxxxx`)، رمز عبور (≥۸ کاراکتر). پس از ثبتنام پیام «در انتظار تأیید مدیر سیستم هستید» نمایش داده میشود.
2. **ورود**: کاربران `pending` → «در انتظار تأیید»، `rejected` → «حساب رد شده». ورود موفق: متربی → `/dashboard`، مدیر → `/admin`.
3. **محدودیت دسترسی**: نقشهای غیرمتربی به `/dashboard` دسترسی ندارند. کاربران تأییدنشده امکان ورود ندارند.

#### تکالیف و ارسال
4. **مشاهده دورههای فعال**: در نوار کناری فقط دورههای `active` نمایش داده میشود.
5. **تایملاین تکالیف**: محور افقی با دایرههای رنگی (سبز=گذشته، آبی=امروز، خاکستری=آینده). کلیک → مودال جزئیات.
6. **جزئیات تکلیف**: عنوان، تاریخ، توضیحات، دستورالعمل، فایلهای ضمیمه (قابل پخش/دانلود)، وضعیت تحویل، نمره روزانه و تجمعی، بازخورد.
7. **قانون ۳ بار گوشدادن (Listen Gate)**: تا ۳ بار کامل گوش نکردن، دکمه ضبط غیرفعال است. شمارنده شفاف: `تعداد گوشدادن: X / 3`.
8. **ضبط و ارسال صدا**: `MediaRecorder` با نمایش «● در حال ضبط...». ارسال با `FormData` (فیلد `audioFile`).
9. **تاریخچه ارسالها**: کارتهای مجزا شامل عنوان، تاریخ، نمره، وضعیت، پخشکننده صوت، بازخورد.
10. **پروفایل**: مودال شامل نام، نامخانوادگی، ایمیل، تلفن، نقش، وضعیت حساب.
11. **خروج**: پاک کردن `localStorage` و هدایت به `/auth/login`.

#### مسیر رشد و معنویت
12. **مسیر رشد**: مشاهده جایگاه خود در نقشه راه، مقامات کسبشده (فعال) و بعدی (قفل).
13. **مسیر معنوی**: تمرین روزانه، مناسبتها، تاریخچه، 🔥 streak.
14. **فعالیت بدنی**: فرم روزانه (دقیقه/قدم/خواب/یادداشت)، نوار ۷روزه، streak.

#### جدید (از نظرسنجی)
15. **مشاهده دفترچه ماهانه**: خلاصه پیشرفت، بازخورد مربی، مراحل بعدی. تولید خودکار پایان ماه.
16. **مشاهده تقویم مناسبتها**: مراسمات، اردوها، جلسات. جزئیات با کلیک.
17. **مشاهده گزارش فردی**: پیشرفت به تفکیک هدف (قرآن، ریاضی، آداب،...) با سطح مهارت و درصد.

### ۴.۲. مربی (۱۴ داستان) 🆕

#### مدیریت حلقه
1. **مشاهده متربیان حلقه**: لیست متربیان با وضعیت، نمرات، حضور.
2. **مدیریت تکالیف حلقه**: ایجاد، ویرایش، حذف تکالیف برای حلقه خود.
3. **نمرهدهی و بازخورد**: ثبت نمره روزانه و تجمعی + بازخورد متنی/صوتی.
4. **مدیریت ضمیمهها**: افزودن فایل صوتی آموزشی، تصویر، مستندات به تکلیف.

#### گزارش و پایش
5. **ثبت گزارش فردی متربی**: فرم شامل انتخاب متربی، هدف، سطح مهارت، درصد پیشرفت، یادداشت. والدین اعلان دریافت میکنند. لحاظ در دفترچه ماهانه.
6. **مشاهده نمودار پیشرفت**: نمودار دو هفتهای پیشرفت هر متربی به تفکیک هدف.
7. **مشاهده تاریخچه ارسالها**: همه ارسالهای متربیان حلقه با نمرات و بازخورد.

#### ارتباطات
8. **ارتباط با متربی**: پیامرسانی دوطرفه.
9. **ارتباط با والدین**: پیامرسانی دوطرفه + گزارش مشترک پیشرفت.
10. **ارتباط با مسئول شعبه**: ارسال برنامه، دریافت ارزیابی.

#### ستادی
11. **درخواست اردو**: ثبت درخواست، پیگیری وضعیت.
12. **درخواست سرویس لجستیک**: فرم شامل مبدأ، مقصد، تاریخ، ساعت، تعداد نفرات. تأیید مسئول شعبه و امور مالی.
13. **طرح درس روزانه**: ارسال به مسئول شعبه.
14. **برنامه رشد شخصی**: برنامه سازمانی + شخصی + مسیر رشد.

### ۴.۳. والدین (۱۰ داستان) 🆕

#### مشاهده وضعیت فرزند
1. **مشاهده گزارش فردی فرزند**: پیشرفت به تفکیک هدف (قرآن، ریاضی، آداب،...)، سطح مهارت، درصد، بازخورد مربی. اعلان خودکار هنگام بهروزرسانی.
2. **مشاهده نمودار پیشرفت**: نمودار دو هفتهای فرزند.
3. **مشاهده تکالیف و نمرات**: لیست تکالیف، نمرات، وضعیت تحویل.
4. **مشاهده مسیر رشد**: جایگاه فرزند در نقشه راه، مقامات کسبشده.

#### ارتباطات
5. **ارتباط با مربی**: پیامرسانی دوطرفه.
6. **ارتباط با مسئول شعبه**: پیامرسانی دوطرفه.
7. **ارتباط با امور مالی**: پیگیری پرداختها.

#### تقویم و دفترچه
8. **مشاهده تقویم مناسبتها**: مراسمات، اردوها، جلسات. ثبت حضور/انصراف.
9. **تأیید دفترچه ماهانه فرزند**: مشاهده خلاصه پیشرفت، بازخورد مربی، ثبت تأیید یا نظر.
10. **درخواست سرویس لجستیک**: فرم شامل مبدأ، مقصد، تاریخ، ساعت. پیگیری وضعیت.

### ۴.۴. مدیر سیستم (۹ داستان)

1. **مدیریت کاربران**: مشاهده لیست در انتظار تأیید (`GET /admin/users/pending`)، تأیید (تکمیل اطلاعات متربی + انتخاب دوره)، رد.
2. **مدیریت دورهها**: ایجاد، ویرایش، حذف، جستجو، فیلتر بر اساس وضعیت.
3. **مدیریت تکالیف**: ایجاد با عنوان، تاریخ، توضیحات، دستورالعمل، حداکثر نمره. ایجاد سری تکالیف روزانه (مثلاً ۱۲ روز متوالی).
4. **مدیریت ضمیمهها**: فایل صوتی، تصویری، مستندات.
5. **آمار سیستم**: تعداد دورهها، تکالیف، ضمیمهها، دورههای فعال. گزارش دوره خاص.
6. **مشاهده گزارشهای کلان**: آمار کلی کاربران، مکتبها، شعبهها. نمودار پیشرفت کلی. گزارش عملکرد هر شعبه. گزارش مالی.
7. **مدیریت شعبهها**: ایجاد، ویرایش، غیرفعالسازی.
8. **مدیریت نقشها**: تخصیص نقش به کاربران.
9. **مدیریت محتوای آموزشی**: ویرایش/حذف/اضافه محتوا.

```sql
-- ========== پیامرسانی ==========
CREATE TABLE messages (
id UNIQUEIDENTIFIER PRIMARY KEY DEFAULT NEWID(),
sender_id UNIQUEIDENTIFIER NOT NULL REFERENCES users(id),
receiver_id UNIQUEIDENTIFIER NOT NULL REFERENCES users(id),
subject NVARCHAR(200),
body NVARCHAR(MAX) NOT NULL,
message_type INT DEFAULT 0, -- 0=text, 1=audio, 2=image, 3=file

is_read BIT DEFAULT 0,
parent_message_id UNIQUEIDENTIFIER NULL REFERENCES messages(id), -- برای پاسخ

);

CREATE TABLE parent_murabbi_connections (
id UNIQUEIDENTIFIER PRIMARY KEY DEFAULT NEWID(),

murabbi_id UNIQUEIDENTIFIER NOT NULL REFERENCES users(id),
trainee_id UNIQUEIDENTIFIER NOT NULL REFERENCES users(id), -- فرزند
status INT DEFAULT 0, -- 0=pending, 1=active, 2=blocked
created_at DATETIME2 DEFAULT GETDATE(),
UNIQUE(parent_id, murabbi_id, trainee_id)
);

CREATE TABLE murabbi_halgheh (
id UNIQUEIDENTIFIER PRIMARY KEY DEFAULT NEWID(),

status INT DEFAULT 1,
created_at DATETIME2 DEFAULT GETDATE(),
UNIQUE(murabbi_id, halgheh_id, maktab_id)
);

-- ========== نمرهدهی مربی ==========
CREATE TABLE murabbi_gradings (
id UNIQUEIDENTIFIER PRIMARY KEY DEFAULT NEWID(),

murabbi_id UNIQUEIDENTIFIER NOT NULL REFERENCES users(id),
daily_score DECIMAL(5,2),
cumulative_score DECIMAL(5,2),
feedback NVARCHAR(MAX),
feedback_audio_url NVARCHAR(500),
graded_at DATETIME2 DEFAULT GETDATE()
);

-- ========== درخواست اردو ==========
CREATE TABLE excursion_requests (
id UNIQUEIDENTIFIER PRIMARY KEY DEFAULT NEWID(),
requested_by UNIQUEIDENTIFIER NOT NULL REFERENCES users(id),
title NVARCHAR(200) NOT NULL,
description NVARCHAR(MAX),
proposed_date DATE,
destination NVARCHAR(200),
estimated_cost DECIMAL(18,2),
status INT DEFAULT 0, -- 0=pending, 1=approved, 2=rejected, 3=cancelled
approved_by UNIQUEIDENTIFIER NULL REFERENCES users(id),
created_at DATETIME2 DEFAULT GETDATE()
);
```
