## ۸. فرآیندهای کاری

### ۸.۱. ثبتنام و تأیید

1. کاربر فرم ثبتنام را پر میکند
2. کاربر با وضعیت `pending` ایجاد میشود
3. مدیر از داشبورد مدیریت، کاربران در انتظار تأیید را مشاهده میکند
4. مدیر اطلاعات متربی را تکمیل و کاربر را تأیید میکند
5. کاربر تأییدشده میتواند وارد سیستم شود

### ۸.۲. گردش کار تکلیف روزانه

1. مربی (یا مدیر) تکلیف روزانه با تاریخ مشخص ایجاد میکند
2. متربی در داشبورد خود، تکلیف را در تایملاین مشاهده میکند
3. متربی فایل صوتی آموزشی را گوش میدهد (۳ بار کامل)
4. پس از فعال شدن ضبط، صوت خود را ضبط و ارسال میکند
5. مربی نمره و بازخورد ثبت میکند
6. متربی نتیجه را در تاریخچه مشاهده میکند
7. **گزارش فردی متربی بهروزرسانی میشود** 🆕
8. **والدین اعلان دریافت میکنند** 🆕

### ۸.۳. گردش کار گزارش فردی 🆕

```
[مربی] → ثبت/بهروزرسانی گزارش فردی متربی
├── انتخاب متربی
├── انتخاب هدف (قرآن، ریاضی، آداب،...)
├── سطح مهارت (0-4)
├── درصد پیشرفت
└── یادداشت
↓
[سیستم] → بهروزرسانی student_skill_progress
↓
[سیستم] → اعلان به والدین
↓
[سیستم] → بهروزرسانی رادار ۶ ساحتی
↓
[سیستم] → لحاظ در دفترچه ماهانه
```

### ۸.۴. گردش کار ارتباط والدین-مربی 🆕

```
[والدین] → درخواست اتصال به مربی فرزند
↓
[مربی] → تأیید اتصال
↓
[سیستم] → فعالسازی کانال پیامرسانی
↓
[والدین و مربی] → تبادل پیام، گزارش، بازخورد
↓
[سیستم] → ثبت تاریخچه ارتباط
```

### ۸.۵. گردش کار نمرهدهی مربی 🆕

```
[متربی] → ارسال تکلیف (صوت/فایل)
↓
[سیستم] → ثبت در assignment_submissions (status=pending)
↓
[مربی] → مشاهده ارسالهای در انتظار
↓
[مربی] → ثبت نمره روزانه + تجمعی + بازخورد (متنی/صوتی)
↓
[سیستم] → بهروزرسانی status=graded
↓
[سیستم] → اعلان به متربی
↓
[سیستم] → بهروزرسانی گزارش فردی + نمودار پیشرفت
```

## ۹. فاز ۴: نمودار پیشرفت (طراحی کامل)

### ۹.۱. مفهوم

نمودار پیشرفت، نمایش بصری عملکرد متربی در بازههای زمانی مختلف است. این نمودار به سه نقش اصلی (متربی، مربی، والدین) دید شفافی از روند رشد میدهد.

### ۹.۲. انواع نمودار

| نوع | بازه | کاربرد | مخاطب |
|---|---|---|---|
| **هفتگی** | ۷ روز | روند کوتاهمدت، انگیزشی | متربی |
| **دو هفتهای** | ۱۴ روز | روند میانمدت (درسپلنر فعلی) | متربی، مربی |
| **ماهانه** | ۳۰ روز | روند بلندمدت | مربی، والدین |
| **مهارت در زمان** | دلخواه | رشد یک مهارت خاص | مربی، والدین |

### ۹.۳. اتصال به StudentSkillProgress

نمودار پیشرفت از دو منبع داده ترکیبی استفاده میکند:

```
┌─────────────────────────────────────────────┐
│ ProgressChartService │
├─────────────────────────────────────────────┤
│ 1. assignment_submissions (نمرات روزانه) │
│ → DailyScore, CumulativeScore │
│ → تاریخ ارسال │
│ │
│ 2. student_skill_progress (گزارش فردی) │
│ → progress_percent به تفکیک هدف │
│ → skill_level (0-4) │
│ → last_assessment_date │
│ │
│ 3. random_evaluations (ارزیابی تصادفی) │
│ → نتیجه ارزیابی (قبولی/ناکامی) │
│ → تاریخ │
└─────────────────────────────────────────────┘
```

### ۹.۵. کامپوننت Angular

```typescript
// features/dashboard/progress-chart/progress-chart.component.ts
import { Component, Input, OnInit, OnDestroy } from '@angular/core';
import { CommonModule } from '@angular/common';
import { ProgressChartService } from '../../../core/services/progress-chart.service';
import { BiweeklyChartData } from '../../../core/models/progress-chart.model';

@Component({
selector: 'lp-progress-chart',
standalone: true,
imports: [CommonModule],
templateUrl: './progress-chart.component.html',
styleUrls: ['./progress-chart.component.scss'],
changeDetection: ChangeDetectionStrategy.OnPush
})
export class ProgressChartComponent implements OnInit, OnDestroy {
@Input() traineeId! : number;
@Input() period: 'weekly' | 'biweekly' | 'monthly' = 'biweekly';

data: BiweeklyChartData | null = null;
loading = false;
error: string | null = null;

// SVG dimensions
svgWidth = 600;
svgHeight = 300;
padding = 40;

constructor(private progressChartService: ProgressChartService) {}

ngOnInit(): void {
this.loadChart();
}

ngOnDestroy(): void {
// cleanup subscriptions
}

private loadChart(): void {
this.loading = true;
this.error = null;

this.progressChartService.getBiweeklyChart(this.traineeId).subscribe({
next: (data) => {
this.data = data;
this.loading = false;
},
error: (err) => {
this.error = err.error?.message || 'خطا در دریافت نمودار';
this.loading = false;
}
});
}

// محاسبه مختصات SVG برای خط نمره روزانه
getDailyScorePoints(): string {
if (! this.data || this.data.dailyScores.length === 0) return '';

const chartWidth = this.svgWidth - (this.padding * 2);
const chartHeight = this.svgHeight - (this.padding * 2);
const stepX = chartWidth / Math.max(this.data.dailyScores.length - 1, 1);

return this.data.dailyScores.map((item, index) => {
const x = this.padding + (index * stepX);
const y = this.svgHeight - this.padding - ((item.score / 100) * chartHeight);
return `${x},${y}`;
}).join(' ');
}

// محاسبه مختصات SVG برای خط نمره تجمعی
getCumulativeScorePoints(): string {
if (! this.data || this.data.dailyScores.length === 0) return '';

const chartWidth = this.svgWidth - (this.padding * 2);
const chartHeight = this.svgHeight - (this.padding * 2);
const stepX = chartWidth / Math.max(this.data.dailyScores.length - 1, 1);

return this.data.dailyScores.map((item, index) => {
const x = this.padding + (index * stepX);
const y = this.svgHeight - this.padding - ((item.cumulative / 100) * chartHeight);
return `${x},${y}`;
}).join(' ');
}

// نقاط ارزیابی تصادفی
getEvaluationPoints(): { x: number; y: number; result: string; goalName: string }[] {
if (! this.data) return [];

const chartWidth = this.svgWidth - (this.padding * 2);
const chartHeight = this.svgHeight - (this.padding * 2);
const stepX = chartWidth / Math.max(this.data.dailyScores.length - 1, 1);

return this.data.evaluations.map((evalItem) => {
const index = this.data!.dailyScores.findIndex(d => d.date === evalItem.date);
const x = this.padding + (Math.max(index, 0) * stepX);
const y = this.svgHeight - this.padding - ((evalItem.result === 'passed' ? 85: 15) / 100 * chartHeight);
return { x, y, result: evalItem.result, goalName: evalItem.goalName };
});
}

// برچسبهای محور X
getXAxisLabels(): string[] {
if (! this.data) return [];
return this.data.dailyScores.map(d => {
const date = new Date(d.date);
return `${date.getMonth() + 1}/${date.getDate()}`;
});
}
}
```

### ۱۰.۳. کامپوننت گزارش فردی (مشترک مربی/والدین)

```typescript
// features/shared/trainee-progress/trainee-progress.component.ts
import { Component, Input, OnInit } from '@angular/core';
import { CommonModule } from '@angular/common';
import { ProgressChartComponent } from '../../dashboard/progress-chart/progress-chart.component';

@Component({
selector: 'lp-trainee-progress',
standalone: true,
imports: [CommonModule, ProgressChartComponent],
templateUrl: './trainee-progress.component.html',
styleUrls: ['./trainee-progress.component.scss']
})
export class TraineeProgressComponent implements OnInit {
@Input() traineeId! : number;
@Input() mode: 'view' | 'edit' = 'view'; // والدین: view، مربی: edit

// داده گزارش فردی
skillProgress: SkillProgress[] = [];
radarData: RadarData | null = null;
loading = false;

constructor(
private progressService: StudentProgressService,
private radarService: RadarService
) {}

ngOnInit(): void {
this.loadProgress();
this.loadRadar();
}

private loadProgress(): void {
this.loading = true;
this.progressService.getStudentProgress(this.traineeId).subscribe({
next: (data) => {
this.skillProgress = data.goals;
this.loading = false;
},
error: () => { this.loading = false; }
});
}

private loadRadar(): void {
this.radarService.getRadarData(this.traineeId).subscribe({
next: (data) => { this.radarData = data; }
});
}

// برای حالت ویرایش (مربی)
updateSkillLevel(goalId: number, level: number): void {
if (this.mode! == 'edit') return;
this.progressService.updateSkillLevel(this.traineeId, goalId, level).subscribe();
}
}
```

### ۱۰.۴. کامپوننت پیامرسانی

```typescript
// features/shared/messaging/messaging.component.ts
import { Component, Input, OnInit } from '@angular/core';
import { CommonModule } from '@angular/common';
import { MessageService } from '../../../core/services/message.service';

@Component({
selector: 'lp-messaging',
standalone: true,
imports: [CommonModule],
templateUrl: './messaging.component.html',
styleUrls: ['./messaging.component.scss']
})
export class MessagingComponent implements OnInit {
@Input() conversationWith! : number; // شناسه کاربر مقابل
@Input() context: 'trainee' | 'parent' | 'murabbi' | 'admin' = 'trainee';

messages: Message[] = [];
newMessage = '';
loading = false;

constructor(private messageService: MessageService) {}

ngOnInit(): void {
this.loadMessages();
}

private loadMessages(): void {
this.loading = true;
this.messageService.getConversation(this.conversationWith).subscribe({
next: (data) => {
this.messages = data;
this.loading = false;
},
error: () => { this.loading = false; }
});
}

sendMessage(): void {
if (! this.newMessage.trim()) return;

this.messageService.sendMessage(this.conversationWith, this.newMessage).subscribe({
next: (message) => {
this.messages.push(message);
this.newMessage = '';
}
});
}
}
```

## ۱۱. نیازمندیهای غیرعملکردی

| حوزه | وضعیت فعلی |
|------|-----------|
| **امنیت** | احراز هویت با `dummy-token` در localStorage (موقتی — نیاز به JWT واقعی) |
| **CORS** | کاملاً باز (`AllowAnyOrigin`) — نیاز به محدودسازی در تولید |
| **RTL/فارسی** | پشتیبانی کامل با فونت وزیرمتن |
| **موبایل** | پشتیبانی اندروید با Capacitor 8 |
| **مدیریت خطا** | نمایش پیام خطا از `error.error.message` |
| **API دوگانه** | قابلیت جابهجایی HTTP/Mock بدون تغییر کامپوننتها |
| **تست** | Vitest با jsdom |
| **شمارنده گوشدادن** | پایدار در حالت Mock (localStorage) |
| **عملکرد** | Lazy-load تمام feature modules؛ OnPush change detection؛ virtual scroll |
| **حریم خصوصی** | Portfolio پیشفرض private؛ اشتراکگذاری explicit opt-in |
