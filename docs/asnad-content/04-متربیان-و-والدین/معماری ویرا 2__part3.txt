## ۱۳. ریسکها و ملاحظات

| ریسک | کاهشریسک |
|---|---|
| **شلوغی داشبورد** | اصل «خلاصه در خانه، عمق در تب» — داشبورد فقط KPIها + Radar + ۳ کارت اصلی |
| **فشار بر متربی (Gamification overdose)** | XP/نشانها اختیاری و مخفیپذیر؛ تمرکز روی Mastery/Streak ذاتی |
| **نقش والدین/مربی (سهجانبه بودن)** | هر متریک در `student-progress` برای والد/مربی قابل مشاهده باشد |
| **حریم خصوصی** | Portfolio پیشفرض private؛ اشتراکگذاری explicit opt-in |
| **EnsureCreated / بدون Migration** | Entityهای جدید با `EnsureCreated()` سازگار باشند؛ `--seed` برای دادههای اولیه |
| **عملکرد** | Lazy-load تمام feature modules؛ OnPush change detection؛ virtual scroll |
| **اتصال SRS به ارزیابی** | الگوریتم انتخاب تصادفی باید منصفانه باشد — SRS فقط اولویت میدهد، حذف نمیکند |
| **پیامرسانی** | نیاز به SignalR برای پیامرسانی بلادرنگ در نسخههای بعدی |
| **نقش مربی** | تعریف دقیق مرز مسئولیت مربی و مدیر برای جلوگیری از تداخل |
