## 1. Project Overview

**nehzat-plus** (Lesson Planner) — An educational platform for Quranic, Arabic, Persian literature, Math, and Sciences education with role-based dashboards, learning paths, and spiritual tracking.

### Tech Stack

| Layer | Technology | Version |
|-------|------------|---------|
| **Backend** | ASP.NET Core | 10.0 (net10.0) |
| **Database** | SQL Server | Windows Auth (Trusted_Connection) |
| **ORM** | EF Core | 10.0 (EnsureCreated only — no migrations) |
| **Auth** | OTUH2 OIDC | Redirect-based, MockAuth in Dev |
| **Frontend** | Angular | 21 (standalone, signals, OnPush) |
| **Mobile** | Capacitor | 8 (Android only, `com.nsafari.lessonplanner`) |
| **Build** | Vite/ng | Output: `dist/frontend/browser` |

### Dependency Rule
`Domain → Application → Infrastructure → API` (inward only)

### Key Conventions
- **Entity tables**: `Nehzat_` prefix (`Nehzat_users`, `Nehzat_courses`, `Nehzat_study_lessons`)
- **User entity**: `OidcSubject` replaces `PasswordHash` — no local passwords
- **Auth**: OTUH2 redirect-based OIDC (MockAuth in Dev via `DevAuth:UseMockAuth`)
- **Services**: ~40 scoped `I*Service` registered explicitly in `Program.cs`
- **Controllers**: Split by domain (8 Admin sub-controllers, no monolithic AdminController)

## 4. Current Features (Implemented)

### 4.1 Authentication
- **OTUH2 OIDC** redirect flow (`/auth/login` → OTUH2 → `/auth/callback`)
- **MockAuth** in Dev: any credentials → manager claims
- **Tokens**: Access+ID in `sessionStorage`, Refresh in `localStorage`
- **401** → auto-logout

### 4.2 Dashboard (Trainee)
- **Phase system**: A/B (child), C (pre-teen), D (teen), E (young adult)
- **Phase A/B**: `DashboardChildComponent` — 4 cards (Games, Lessons, Draw, Rewards)
- **Phase C–E**: `DashboardComponent` — Courses, Timeline, Recordings, Submissions, Assessments, Nudges

### 4.3 Learning Path (`/dashboard/learning-path`)
- **LearningPathComponent** — Grid of paths, drill-down tree (Levels → Modules → Lessons)
- **LessonDetailPageComponent** (`/lesson/:id`) — Content blocks (text/audio/video/image), Quiz tabs
- **Phase-aware theming**: child-theme (A/B) / teen-theme (C–E)
- **Router outlet** for lesson detail

### 4.4 Parent Dashboard (`/parent`)
- **ParentPanelComponent** — Children list with progress cards
- **StudentProgressCardComponent** — Phase badges, progress
- **MonthlyBookletComponent** — Persian calendar, booklet management
- **ParentStudentDetailComponent** — Summary cards, subjects, skills, charts, feedback, submissions

### 4.5 Admin (8 Sub-controllers)
- `AdminBranchesController`, `AdminCoursesController`, `AdminCoachesController`
- `AdminBranchManagersController`, `AdminParentsController`, `AdminEvaluatorsController`
- `AdminStudentsController`, `AdminStatisticsController`

### 4.6 Other Domains (30+ features)
- **Quran**: Rings, Surahs, Progress widget, Memorization tracking
- **Math**: Topics, Questions, Progress
- **Arabic/Persian Literature**: Poets, Lessons, Quizzes
- **Halgheh**: Circles, Assignments, Members
- **Maktab**: Schools, Members, Reports
- **Career Pathways**, **Portfolio**, **Project Defense**, **Surveys**, **Messaging**, **Notifications**, **Map/Courier**, **AI Assistant**, **Vocabulary**, **Training Courses**
